# Робочі правила Codex для «Десь не там»

Прочитай `CODEX_TZ_DES_NE_TAM.md` перед роботою. Гра – мобільна текстова хорор-комедія українською, з легкою суржиковою лексикою й авторською 2D folk-horror мальовкою.

- Усі глави 1–7, їхні репліки, жарти, сюжетні факти й персонажі – канон. Не переписувати без погодження.
- Не розкривати Дарину/Постать до належної сцени 7 глави: вона впізнала Степана ще в 2-й главі; він упізнав її під час зняття каптура в 7-й.
- Наприкінці 7-ї глави Степан і Дарина ще в тумані. Не починати 8-му главу з готового зібрання всіх у селі без сцени повернення.
- Не робити главу 8 фінальною й не вигадувати замість авторки пояснення туману, прокляття, дорослого сина або Семенової мотивації.
- Зберегти робочі сейви, наслідки виборів, прогрес, характеристики, стани, відносини, інвентар, бойові та тестові механіки. Міграції обов'язкові.
- Підтримувати GitHub Pages і мобільний Safari. Зміни невеликі, послідовні, з тестами.
- Не генерувати й не підміняти арти без доручення. Під час майбутнього оновлення Степана залишити просту мальовку, великі форми й гіперболізовані емоції.
- Не робити push у старий `ilonadzyu-cloud/Test-`; жодного push у новий репозиторій без підтвердження.
- **Поточне завдання: тільки технічний аудит**. Повернути звіт і план; не реалізовувати весь список відразу.
