# Перевірка на справжньому телефоні

Виконати на iPhone/Safari та Android/Chrome. Доступна автоматизація використовувала Chrome на Windows; ці перевірки ще не виконані. Після публікації робочої гілки використовувати її тестовий сайт, або локальний HTTP-сервер із доступом через мережу Windows. Не змінювати main для тестування.

| Дія | Очікуваний результат |
|---|---|
| Почати нову гру; відкрити всі розділи меню | Великий авторський арт, читабельний текст, кнопки доступні, горизонтального прокручування немає |
| Повернути телефон, змінити розмір тексту | Текст і кнопки доступні, низ екрана не перекриває системна панель |
| Увімкнути звук після торкання; перейти між сценами й меню; вимкнути | Один фоновий трек, звук вимикається і налаштування зберігається |
| Читати та відкривати меню кілька хвилин | Ігровий час і потреби не змінюються від читання |
| Пройти денну й нічну стежку | Витрачаються ігровий час та енергія, ніч змінює ризики |
| Зібрати ресурс, повернутися, повторити, закрити й відкрити вкладку | Запас зменшений і не відновлюється від відкриття меню або завантаження |
| Заповнити сумку; приготувати страву або скласти бинт | Перевірена вага, списання матеріалів одноразове; невдала дія не втрачає матеріали |
| Відкласти річ і змінити локацію | Річ залишається на місці, її не можна забрати дистанційно |
| Бій: перемогти, сховатися, втекти, програти | Різні наслідки; відхід доступний без енергії; польова поразка не створює безвиході |
| У бою відкрити прокачку, одяг та інвентар | Підготовка заблокована; лікування можливе бойовою дією з ходом противника |
| Зберегти незавершену сутичку; закрити вкладку й продовжити | Зберігаються HP противника, хід та використані здібності |
| Глава 6: пройти три пригоди Євпапія | Його ресурси окремі, нагорода не повторюється; перевірене повідомлення можна передати Галі |
| Сало, травма крил, образа та велич; відпочинок | Стани реально впливають на дії й минають за ігровим часом |
| Ручний сейв; експорт; імпорт копії та старого сейва | Зберігаються ресурси, наслідки, стани, прогрес, дослідження та правильний герой |
| Глава 7: каптур, розкриття, син, кінець глави | Немає передчасного обличчя, одна Дарина; видно землю в тумані; герої лишаються в тумані |

Перший крок продовження: повністю пройти главу 6 із картою та трьома пригодами, оцінити час і ресурсну ціну поруч із канонічними репліками. Потім перевірити стани/сейви/звук за цією таблицею. Записати модель телефона, браузер, кроки та фактичний результат.
